# Owner Management Screens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Owner Agenda labels/title; list-first Barbers / Services / Customers screens with a circular `+` button (FAB) opening dedicated create screens, and Edit opening a dedicated screen (barber profile for barbers); red "Desativar"; search fields with clear (X).

**Architecture:** Flat hidden-tab routes (no nested layouts, per `app/(owner)/_layout.tsx` pattern): `barber-new`, `barber-profile`, `service-form` (create+edit via optional `id`), `customer-form` (create+edit via optional `id`). Existing API functions are reused unchanged; the forms and editors move out of the three list screens into the new screens and shared components. Back navigation relies on Plan 1 (`backBehavior="history"`).

**Tech Stack:** Expo Router `Tabs`, React Query, NativeWind, Playwright web e2e, Jest.

**Spec:** `docs/superpowers/plans/2026-10-20-ux-overhaul-index.md`

## Global Constraints
- Branch `feat-owner-management` from `main`; **after Plans 1, 2 and 4** (needs `useBack(fallback)`, `NotificationBell` already on owner agenda, `SearchInput`).
- Red destructive buttons use `Button variant="danger"` (the existing token `danger-500 #DC3B30`), never a new colour.
- FAB: 56px circle, `bg-primary-400`, lucide `Plus` in `colors.ink`, absolutely positioned `bottom-6 right-5` inside the screen's root `Screen` (above the bottom tab bar, which lives outside the scene), `accessibilityLabel` per screen, `testID="fab-add"`.
- Owner editing a barber covers: name (kept from today's Edit), invite/account, compensation, services & prices, activate/deactivate (decision of 2026-10-20; photo/phone/hours are the barber's own).
- Agenda title follows the selected view ("Agenda do dia" for Dia, "Agenda da semana", "Agenda do mês") — extrapolation of the request "Agenda do dia"; flagged in the PR.
- Memory: TDD, `rtk`, verify UI in browser at 375px (screenshots + computed CSS), jest only `tests/**/*.test.ts`, owner e2e live in `tests/e2e/owner-*.web.spec.ts` (move `.env.local` aside to run).
